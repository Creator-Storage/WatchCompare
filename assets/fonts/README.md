# Local Pin Sans fonts

WatchCompare is configured around the four Pin Sans MacOS weights supplied for this project:

- `Pin-Sans-MacOS-Regular-708c49dd.ttf`
- `Pin-Sans-MacOS-Medium-704a4f34.ttf`
- `Pin-Sans-MacOS-Bold-ce475d98.ttf`
- `Pin-Sans-MacOS-Heavy-2b6abf8c.ttf`

Font binaries are intentionally not committed to this public repository. Put authorized local copies in this directory when running fidelity tests. The renderer will eventually resolve these weights from the project asset store rather than relying on operating-system font substitution.
